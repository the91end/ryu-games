# Flash card sounds

Drop real recordings in `sounds/<category id>/<card id>.mp3`, using the ids
from `games/flashcards-data.js`. Examples:

    sounds/animals/dog.mp3
    sounds/animals/cow.mp3
    sounds/vehicles/train.mp3

When a card has a `sound` but no recording exists, the game speaks the sound
instead ("Woof woof!" in English, "Guk guk!" in Indonesian).

Free, properly licensed sources: freesound.org (check each clip's license —
CC0 is easiest), or record your own.
